# 显式正式账号配置

工具支持单机本地密码账号，操作员明确指定 employee、it 或 security；不会把演示账号转换成正式权限，也不会修改已存在账号的密码、角色或启用状态。

先对明确数据库备份并迁移，再在后端目录预览：

```powershell
.\.venv\Scripts\python.exe scripts/provision_user.py --email operator@company.example --name "Assigned Operator" --role security
```

创建时加 `--apply --backup F:/Private/ESAA/before-new-account.db`。备份路径必须不存在；工具先完成校验快照，再在同一事务创建账号和必需审计。密码通过交互式隐藏输入并重复确认；无人值守可从受限环境注入 `ESAA_INITIAL_PASSWORD`，不能作为命令参数或写入报告。

工具强制至少 14 字符、最多 72 UTF-8 字节、字母与数字及至少三种字符类别，拒绝包含邮箱用户名/姓名词、与演示密码相同的值。拒绝已知演示邮箱、保留技术身份及大小写重复邮箱。它没有实现组织词库、泄露密码库、跨系统复用检测、SSO/MFA或审批；这些要求须接入正式身份体系，不应称为完整企业密码策略。

先实际验证新账号登录与权限，再按通知文档停用原演示账号并撤销会话。本轮只创建模拟隔离账号用于验收，没有向现有业务库添加身份或分配正式职责。三类角色的真实登录、访问边界、备份、审计、重复身份拒绝及错误输出隐私已通过 9 项验收。
