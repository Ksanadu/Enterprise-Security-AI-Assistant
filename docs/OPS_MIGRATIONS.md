# 迁移、共享限流与定时清理

## 数据库版本

引入 Alembic 1.20，版本 `20261012_01` 固定当前原型表结构，`20261012_02` 添加共享安全预算表，`20261012_03` 添加通知队列。迁移脚本是明确的 DDL；初始结构快照包含字段、默认值、索引、唯一约束和外键。后续修改需要新的版本，不能修改已发布迁移。

2026-10-13 增加 `20261013_04`：四类已擦除身份标记及保全表。回退遇到擦除记录或任意保全历史会拒绝，防止旧查询暴露标记记录。生产库仍须操作员先备份、审阅并迁移；本轮没有迁移现有业务库。参见 [业务保留](OPS_RETENTION.md)。

已有无版本数据库只有符合冻结结构时才能被接纳；缺少的已知表可以创建。未知字段、约束或表会使迁移失败，保持数据。开发环境自动删表重建已移除。生产启动只检查已应用版本，不自动运行 DDL。

先按 [备份恢复说明](OPS_BACKUP.md) 完成备份，在后端目录运行：

```powershell
cd backend
.\.venv\Scripts\python.exe -m alembic current
.\.venv\Scripts\python.exe -m alembic upgrade head
```

数据库 URL 从环境配置读取，不把包含密码的 URL 放进命令行。SQLite 升级取得短写锁并置于事务中；迁移应作为部署时的一次性操作，完成后再启动多个生产 worker。另一个数据库需要驱动、DDL、事务和查询验收，当前仅声明 SQLite 单机试点支持。

回退会删除表的版本在存在数据时拒绝执行：初始版本保护业务行，共享预算版本保护仍存储的安全预算。实际发布回滚应冻结写入、使用已校验备份及对应构建，不能把空库 `downgrade` 演练当作业务发布回滚。

实现参考 [Alembic 迁移文档](https://alembic.sqlalchemy.org/en/latest/tutorial.html) 和 [自动生成审阅要求](https://alembic.sqlalchemy.org/en/latest/autogenerate.html)。自动生成只是候选脚本，本轮已修复生成草稿的 SQLite 时间默认值问题并实际复验。

## 共享安全预算

默认 `SHARED_SECURITY_LIMITS=true`。聊天、知识查询、登录账号和来源地址使用分别命名的持久化预算，多个 worker 共用同一 SQLite 文件与稳定签名秘密。键为 HMAC，预算表不保存原始邮箱或 IP。

登录在验证密码前原子预留账号和来源地址名额，不能仅先检查再事后记失败。预留有 `AUTH_ATTEMPT_LEASE_SECONDS` 租约，进程崩溃后可以回收；实际失败触发独立的锁定期限。成功登录保留其他请求的预留以及地址失败计数。共享存储不可用时返回 503，禁止降级到进程内预算；`/ready` 同步失败。

进程内实现保留给测试或单进程演示；生产配置拒绝关闭共享预算。SQLite 写事务串行化适用于当前单机试点，扩容和性能上限仍需负载验收。

## 实际清理入口

应用生命周期启动 `MAINTENANCE_INTERVAL_SECONDS` 定时任务（默认 300 秒）。每次最多清理 1000 个过期预算和 1000 个超过会话保留期的过期认证会话。有效锁定和登录预留的到期时间纳入保留条件，不通过清理重置活跃预算。

清理统计写入日志，有实际删除时记录审计。失败保留类别并等待下一次运行。生产配置拒绝关闭该任务。2026-10-13 起该入口可执行显式批准的业务保留政策；配置为空则只执行原预算/会话维护。期限、保全、备份与物理擦除边界见 [OPS_RETENTION.md](OPS_RETENTION.md)。
